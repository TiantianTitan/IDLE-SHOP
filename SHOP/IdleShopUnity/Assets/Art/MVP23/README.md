All assets should be PNG sprites with transparent backgrounds unless the file is a full scene background.

Recommended sizes:
- Full scene background: 1080x720 or 1440x960, opaque PNG.
- Shelf/counter/characters/effects: 512x512 PNG, transparent background.
- UI panels and frames: 512x256 or 1024x512 PNG, transparent background, safe readable center.
- Icons and badges: 256x256 PNG, transparent background.
